# ⚡ Harsh Gautam — Modern Developer Portfolio

A fast, minimalist, and terminal-inspired personal developer portfolio engineered with **Next.js (App Router)**, **TypeScript**, and **Tailwind CSS**.

Tailored to highlight full-stack web architectures, asynchronous APIs (FastAPI & Node.js), relational/NoSQL database systems, and Linux workstation tooling.

---

## 🌟 Highlights & Features

- **Hero & Live Terminal Bio**: High-impact developer headline, status badge (`Available for Full-Stack & AI Roles`), quick-copy CLI command (`$ npx harsh-bio`), direct email handshake, and quick stats.
- **Featured Projects & Architectural Deep-Dives**:
  - **Personal Publishing Engine**: Edge-optimized content platform pairing Next.js App Router on Vercel with an asynchronous FastAPI microservice on Render and Neon PostgreSQL.
  - **Enterprise Task & Ops Platform**: Full-stack MERN operations suite with cryptographically signed JWT auth, role-based access control (RBAC), and MongoDB transactional integrity.
  - **RideLink Urban Mobility Platform**: Modern mobility platform featuring Leaflet maps, 8 vehicle tiers, dynamic surge pricing engine, and driver partner HUD.
  - **Real-Time Weather Intelligence**: Telemetry monitor with debounced search queries, stale-while-revalidate client caching, and reactive atmospheric simulations.
  - **Dotfiles & Automation Toolkit**: Automated workstation provisioning scripts, custom Waybar status modules, and UWSM Wayland session configuration for CachyOS/Arch.
- **Interactive Project Architecture Modals**: Click *"Architecture Details"* on any project card to review complete system designs, trade-offs, and latency metrics.
- **Technical Arsenal**: Categorized competencies across Languages, Frontend, Backend & APIs, Databases, and DevOps & Systems.
- **Embedded In-Browser CLI Terminal**: Interactive terminal emulator supporting commands: `help`, `bio`, `skills`, `projects`, `fastfetch`, `systems`, `contact`, and `clear`.
- **Education & Career Timeline**: Academic foundation in BCA (AI & ML) at Ethics University combined with independent software product engineering track record.
- **Direct Handshake**: Functional contact form with 1-click clipboard copy for email and phone.

## 🚀 Quickstart & Development

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Local Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
```
